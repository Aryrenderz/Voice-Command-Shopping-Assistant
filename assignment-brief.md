**Subject:** Technical Assessment Project - Software Engineering Position

Project: Voice Command Shopping Assistant — a voice-based shopping list
manager with smart suggestions.

## Required features

**1. Voice Input**
- Voice Command Recognition — add items via commands like "Add milk," "I need apples"
- Natural Language Processing — understand varied phrasings ("I want to buy bananas" vs. "Add bananas to my list")
- Multilingual support — voice commands in multiple languages

**2. Smart Suggestions**
- Product recommendations based on history/preferences ("It looks like you're running low on bread")
- Seasonal recommendations
- Substitutes when a product is unavailable or a preferred alternative exists

**3. Shopping List Management**
- Add / remove / modify items by voice ("Remove milk from my list")
- Automatic categorization (dairy, produce, snacks, etc.)
- Quantity management via voice ("Add 2 bottles of water")

**4. Voice-Activated Search**
- Item search by voice, including brand/size/price ("Find me organic apples")
- Price range / brand filtering by voice ("Find toothpaste under $5")

**11. UI/UX**
- Minimalist interface with a simple shopping-list display
- Visual feedback — show recognized items and actions in real time
- Mobile / voice-only optimized interface

**12. Hosting**
- Deploy on a reliable platform (AWS, Firebase, Google Cloud, etc.)

## Technical requirements
- Clean, production-quality code
- Basic error handling
- Loading states
- Simple documentation of the approach

## Technical freedom
- Any frameworks/technologies
- Any free-tier AI/ML services
- Test data from public sources

## Deliverables
1. Working application URL
2. GitHub repository with source code and README
3. Brief write-up of approach (200 words max)

## Timeline
- Deadline: 1st Sep 2025
- Time investment: max 8 hours

- Problem-solving approach
- Code quality
